Enterprise Linux & Systems Mastery

Complete production Linux engineering matrix covering server administration, file systems, permissions, process lifecycle, networking diagnostics, systemd services, and shell automation.

TOPIC 01 Core & OS

Linux Basics & Host Identity

What is Linux & why it powers 95%+ of DevOps cloud servers. Inspecting OS kernel architecture, hostname configuration, active user identity, server timestamps, and load averages.

uname -a && hostname && whoami && uptime
uname -a hostname whoami date uptime
TOPIC 02 Filesystem

Filesystem Hierarchy (FHS)

Standard Linux directory tree structure: /, /bin (binaries), /etc (configs), /home, /var (logs/spool), /tmp, /usr, /opt (third-party), /root, /dev, /proc (virtual kernel data).

pwd && ls -la /etc /var/log /opt
/etc & /var pwd ls ls -l ls -la
TOPIC 03 Navigation

Directory Management

Creating parent directories recursively, switching directories (cd .., cd ~ home), removing empty directories, and recursive directory tree deletions.

mkdir -p /opt/app/{logs,conf,src} && cd ~ && cd ..
mkdir -p cd .. cd ~ rmdir rm -rf
TOPIC 04 Files

File Operations & Lifecycle

Creating empty files with touch, copying single files & recursive folders (cp -r), moving/renaming files (mv), and safe removing.

touch config.yaml && cp -r src/ /backup/ && mv old.txt new.txt
touch cp -r mv (Rename) rm
TOPIC 05 Inspection

File Inspection & Log Tailing

Viewing file content with cat, paginated browsing with less, inspecting first lines with head, and continuous real-time log tailing with tail -f.

tail -f -n 100 /var/log/nginx/access.log | head -n 20
cat less head -n tail -f
TOPIC 06 CLI Editors

CLI File Editors (Vim & Nano)

In-terminal file editing in headless servers. Mastering Vim modes (Normal, Insert i, Command :wq save & quit, :q! force quit, /search) and Nano shortcuts.

vim /etc/nginx/nginx.conf # :wq save & quit, :q! discard
vim nano Insert (i) :wq & :q!
TOPIC 07 Permissions

Permissions & Numeric Modes

Permission layout: type (- file, d dir, l link), Owner/Group/Others. Values: r=4, w=2, x=1. Calculating modes: 754, 640, 700, 740, 453, and symbolic chmod u+x.

chmod 754 deploy.sh && chmod -R 640 /var/www/secret.env
r=4, w=2, x=1 chmod 754 / 640 chmod u+x -rwxr-xr--
TOPIC 08 Ownership

File Ownership (chown & chgrp)

Managing file ownership boundaries. Differentiating Owner vs Group permissions, updating service account ownership recursively (-R), and group updates.

chown -R www-data:www-data /var/www/html && chgrp devops app.jar
chown chgrp User:Group ls -l
TOPIC 09 User Accounts

Linux User Administration

Managing Linux accounts: inspecting /etc/passwd and /etc/shadow, creating user accounts with adduser, switching user context with su -, and account deletion with userdel.

adduser devops_eng && su - devops_eng && cat /etc/passwd
adduser userdel -r su - /etc/passwd
TOPIC 10 Groups

Group Governance & usermod

Creating administrative security groups with groupadd, attaching supplementary groups with usermod -aG (sudo, docker), and auditing user group memberships.

groupadd docker && usermod -aG sudo,docker devops_eng && groups
groupadd usermod -aG groups docker group
TOPIC 11 Privileges

Root User & Sudo Elevation

Understanding superuser root access, sudo elevation (sudo command), full interactive root environment (sudo -i), and configuring least-privilege delegation via visudo.

sudo -i # or sudo systemctl restart nginx via /etc/sudoers
Root User sudo sudo -i visudo
TOPIC 12 Packages

Package Management (APT)

Updating package repositories, performing system upgrades, installing dependencies, searching package databases, and purging unused packages on Debian/Ubuntu servers.

apt update && apt install -y nginx docker.io && apt search python3
apt update apt upgrade apt install apt remove apt search
TOPIC 13 Processes

Process Monitoring & Kill Signals

Inspecting running processes with ps aux, interactive resource tracking with top/htop, filtering process IDs with grep, and sending termination signals (kill, kill -9 SIGKILL).

ps aux | grep nginx && kill -9 <PID> && htop
ps aux top / htop grep process kill -9 (SIGKILL)
TOPIC 14 Systemd

Service Management (systemctl)

Controlling background daemon services via systemd (status, start, stop, restart). Crucial difference: start (runtime) vs enable (auto-start on boot).

systemctl enable --now nginx && systemctl restart docker && systemctl status nginx
systemctl status start vs enable restart/stop daemon-reload
TOPIC 15 Disk Storage

Disk Space & Storage Audits

Checking disk filesystem usage with human-readable df -h, measuring directory storage footprints with du -sh to locate disk bloat, and listing block devices with lsblk.

df -h && du -sh /var/log/* | sort -hr | head -n 5 && lsblk
df -h du -sh lsblk Disk Usage
TOPIC 16 Hardware

RAM, Swap & CPU Diagnostics

Checking physical RAM and swap space memory with free -h, monitoring real-time load, and inspecting CPU core architecture and thread counts with lscpu.

free -h && lscpu && top -b -n 1 | head -n 12
free -h RAM & Swap lscpu CPU Topology
TOPIC 17 Search

Advanced File Search (find)

Locating files and directories across the system: searching by pattern name, extension (*.conf), type (-type f, -type d), size (-size +100M), and modification timestamp.

find /etc -type f -name "*.conf" -size +10k -mtime -7
find -name Find by Extension -type d / f Size & Time
TOPIC 18 Text Search

Pattern Matching with grep

Extracting matching patterns from files and streams. Case-insensitive search (-i), recursive folder search (-r), line numbering (-n), and regex pattern filtering.

grep -rni "DATABASE_URL" /opt/apps/ --color=auto
grep -i grep -r grep -n Regex Search
TOPIC 19 I/O Streams

Pipes & I/O Stream Redirection

Chaining commands with pipe |, output overwrite redirection >, output append redirection >>, input redirection <, and error stream redirection 2>&1.

cat access.log | grep "500" >> server_errors.log 2>&1
Pipe | Overwrite > Append >> Input < stderr 2>&1
TOPIC 20 Data Parsing

Text Processing (awk, sed, cut)

Stream parsing utilities: sorting with sort, deduplicating with uniq -c, counting words/lines with wc -l, field slicing with cut, column extraction with awk, and in-place substitutions with sed.

cut -d: -f1 /etc/passwd | sort | uniq -c && sed -i 's/80/8080/g' app.conf
awk sed -i cut -d sort & uniq wc -l
TOPIC 21 Networking

Network Diagnostics & Ports

Inspecting IP configuration (ip addr), default routing (ip route), ping latency, DNS resolution (nslookup, dig), listening TCP/UDP sockets (ss -tuln), and port connectivity (nc).

ip addr show && ss -tuln | grep 80 && dig +short google.com && nc -zv 127.0.0.1 443
ip addr ss -tuln ping dig / nslookup nc -zv
TOPIC 22 Remote Access

SSH Remote Access & SCP Transfer

Connecting securely to remote EC2/cloud instances using private keys (.pem / id_rsa), key generation with ssh-keygen, remote execution, and secure copying with scp.

ssh -i key.pem ubuntu@10.0.1.50 "systemctl status app" && scp -i key.pem dist.tar.gz ubuntu@host:/opt/
ssh with .pem scp remote copy Key Auth Remote Exec
TOPIC 23 Environment

Environment Variables & PATH

Inspecting system variables with env, printing variables (echo $HOME), creating and exporting variables (export), binary executable resolution with which, and PATH configuration.

export NODE_ENV=production && export PATH=$PATH:/opt/bin && which docker
env export echo $HOME PATH which
TOPIC 24 Logs

System Logs & journalctl

Navigating /var/log (syslog, auth.log, nginx), live log tailing, querying systemd journal logs by service unit (journalctl -u), and filtering by time windows (--since).

journalctl -u nginx.service -f -n 50 --since "1 hour ago"
/var/log tail -f journalctl -u journalctl -f
TOPIC 25 Scheduling

Cron Job Scheduling & Automation

Scheduling recurring automation tasks with cron: editing crontabs with crontab -e, listing jobs with crontab -l, and 5-field syntax (min hr dom mon dow) for scheduled database backups.

crontab -e # 0 2 * * * /opt/scripts/backup.sh > /dev/null 2>&1
crontab -e crontab -l 5-field Syntax Automated Tasks
TOPIC 26 Scripting

Bash Shell Scripting & Automation

Writing production shell scripts: Shebang #!/bin/bash, variables, command substitution $(), conditionals (if [ $? -eq 0 ]), loops (for host in "${SERVERS[@]}"), making executable (chmod +x), and script execution.

#!/bin/bash \nchmod +x deploy.sh && ./deploy.sh # loops, if-conditions & variables
#!/bin/bash Variables Command Sub $() if / for loop chmod +x

Monitoring: CloudWatch 5XX metrics & latency alarms

  name               = "finxserve-production-alb"
  internal           = false
  load_balancer_type = "application"
